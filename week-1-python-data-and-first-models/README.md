# Week 1 — Python, data and first models

**2–7 November**

Python from zero, then real data, then a model that predicts something. No neural networks this week — a simple model you understand beats a complicated one you do not, and everything in Week 2 is measured against the baseline you build here.

## What you will learn this week

- Python: variables, lists, dicts, loops, functions
- NumPy and pandas, and why vectorised code is fast
- Cleaning data, charting it, and spotting bias in it
- Features and labels, train and test splits, overfitting
- Accuracy, precision, recall, F1, and cross-validation

A notebook with your data analysis and a baseline model, a pull request, and a short note on the week — by Saturday 7 November.

## Read this before you start

Two things decide how the rest of your month goes, and both happen in assignment 2. **Choose a domain you are actually curious about** — you look at the same data for four weeks. And **choose a real dataset**, at least 500 rows: a toy dataset gives you nothing to clean, nothing to chart and nothing interesting to model, and Week 3 then has no documents to retrieve from.

## The AI strand this week

None this week. You are learning what the tools do before using an assistant on them — a suggestion you cannot evaluate is not help.
